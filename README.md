# CASASU 배포 저장소

CASASU(AutoCAD 2024~2027 플러그인 — nosasu.com)의 공개 배포처입니다.

- 설치 파일·ZIP: 오른쪽 [Releases]의 최신 릴리스에서 `CASASU-Setup-<버전>.exe`를 받습니다(AutoCAD를 모두 닫고 실행).
- 라이선스 계약: `LICENSE.md`(판마다 그대로 보관) — 설치 화면과 ZIP 안 `LICENSE.txt`에도 같은 글이 있습니다.
- 설명서·알려진 한계: ZIP 안 `README.md`.
- 업데이트 정보: `feed.json`(설치된 CASASU가 자동으로 읽는 파일 — 손으로 고치지 마십시오).
- 문의: nosasu.com
